# 商业计划书

## 一、项目事实摘要

**我们为谁解决什么问题：**
为关注饮食健康的普通用户和有慢性病风险（糖尿病、高血压、高血脂、高尿酸）的人群，解决"不知道吃的东西有多少热量、是否适合自己身体状况"的问题。

**Demo 现在已经能做什么：**
- 拍照上传食物，AI 自动识别并估算热量和营养成分
- 手动录入饮食，内置 85 种中国常见食物数据库
- 提交体检报告（血糖、血压、血脂、尿酸等），系统自动标记健康风险
- 根据健康状况和减重/保持/增重目标，生成个性化饮食建议
- 记录运动消耗，结合饮食计算每日净摄入
- 中医食补养生建议（四季 + 体质调理）
- 三大营养素（蛋白质/碳水/脂肪）摄入进度可视化
- 热量圆环分层展示（摄入/运动消耗/基础代谢），超量变色预警

**最有力的一条证据：**
Demo 已完整实现从"拍照识别食物 → 营养分析 → 个性化建议"的全流程闭环，AI 识别准确率达到可用水平（测试图片成功识别汉堡、薯条、酱料）。

**我们和替代方案最大的不同：**
- 不只是记录工具——打通体检报告，根据个人健康状况给出"能不能吃"的建议
- 本地化食物数据库（中式餐饮），而非西式食物为主的海外竞品
- 中西医结合：现代营养学 + 中医食补养生
- AI 视觉识别直接拍照出结果，无需手动搜索

**下一步最需要验证什么：**
- 真实用户对 AI 识别准确率的满意度
- 体检报告 → 饮食建议的推荐逻辑是否被用户信任
- 用户留存率和使用频率

## 二、项目概况

健康追踪是一款面向中国用户的 AI 饮食健康管理 Web 应用。用户通过拍照即可识别食物、获取热量和营养数据；上传体检报告后，系统根据个人健康状况（糖尿病、高血压、高血脂、高尿酸等风险）和目标（减重/保持/增重）生成个性化饮食建议。产品融合现代营养学与中医食补养生理念，形成"识别-记录-分析-建议"的完整闭环。

当前为 Web PWA 形态，响应式适配手机和桌面端，后续可封装为小程序或 App。

## 三、市场分析

### 3.1 目标用户与市场需求

| 用户群体 | 规模估算 | 核心需求 |
|----------|----------|----------|
| 减重/健身人群 | 中国约 2 亿 | 精准记录热量，控制摄入 |
| 糖尿病患者 | 中国约 1.4 亿 | 控糖饮食指导 |
| 高血压患者 | 中国约 2.45 亿 | 低盐饮食建议 |
| 高尿酸/痛风患者 | 中国约 1.8 亿 | 嘌呤含量查询 |
| 养生保健人群 | 广泛 | 中医食疗、季节调理 |
| 体检后有改善需求者 | 每年约 5 亿人次 | 根据体检报告调整饮食 |

### 3.2 市场痛点

1. **记录太麻烦**：手动输入食物名称、查热量表效率极低，用户难以坚持
2. **不知道该吃什么**：知道自己有高血糖，但不知道面前这盘菜能不能吃
3. **体检报告看不懂**：拿了报告不知道和日常饮食有什么关系
4. **缺乏个性化**：市面上热量 App 千篇一律，不根据个人健康状况调整
5. **中式餐饮识别差**：海外竞品（MyFitnessPal、Lose It）以西餐为主，中餐数据匮乏

### 3.3 替代方案分析

| 竞品 | 优势 | 劣势 |
|------|------|------|
| **薄荷健康** | 国内最大食物数据库，用户量大 | 无 AI 拍照识别，体检关联弱 |
| **MyFitnessPal** | 全球最大，数据库丰富 | 西餐为主，无中文 AI，国内体验差 |
| **Keep 饮食模块** | 运动+饮食一体 | 饮食功能浅，无体检关联 |
| **手动记录（笔记/Excel）** | 灵活 | 耗时，无法持续 |
| **营养师咨询** | 专业个性化 | 费用高（月数百至千元），无法实时 |

**我们的差异点：** AI 拍照 → 自动识别 → 个人健康档案联动 → 中西医结合建议，形成"傻瓜式"使用体验。

## 四、产品与当前 Demo

### 4.1 产品介绍

健康追踪是一款 AI 驱动的饮食健康管理 PWA 应用，核心流程：

> 拍照 → AI 识别食物 → 自动填入营养成分 → 结合用户体检档案和运动数据 → 生成个性化建议

技术上采用 Next.js 全栈架构，接入了小米 MiMo-V2.5 视觉模型实现食物识别，内置 85 种常见中式食物数据库（覆盖主食、肉类、蔬菜、水果、菜肴等），支持 Neon PostgreSQL 云端数据持久化。

| 功能 | 状态 | 说明 |
|------|------|------|

### 4.3 为什么是现在，为什么是我们

**为什么是现在：**
- AI 视觉模型（如 MiMo、通义千问、GPT-4V）已经足够成熟且成本大幅下降，可以准确识别食物
- 中国慢性病患者数量持续增长，饮食管理是刚需
- 年轻人健康意识提升，"养生"成为社交媒体热门话题
- 国内竞品在 AI 识别和个性化方面进展缓慢

**为什么是我们：**
- 打通"体检报告 → 饮食建议"链路，目前国内几乎没有产品做到
- 中西医结合视角，既有科学营养学又有文化认同感
- 全栈自研，技术可控，快速迭代

## 六、商业模式

| 阶段 | 模式 | 说明 |
|------|------|------|
| **初期（验证期）** | 免费 | 积累用户和数据，验证核心功能 |
| **成长期** | Freemium | 基础功能免费，高级功能付费 |
| **成熟期** | 订阅制 + B2B | C 端订阅 + 企业健康管理服务 |

**具体收入来源：**

1. **C 端订阅（主收入）**
   - 免费版：每日 5 次拍照识别，基础建议
   - 付费版（¥19/月或 ¥168/年）：无限拍照识别、AI 深度报告解读、个性化食谱推荐、数据导出

2. **B2B 企业健康管理**
   - 为体检中心、企业 HR 提供员工饮食健康管理平台
   - 按人数收费（¥5-10/人/月）

3. **增值服务**
   - 对接营养师在线咨询（平台抽佣 15-20%）
   - 健康食品/食材电商引流

## 九、风险与下一步

| 风险 | 我们打算怎么应对或验证 |
|------|----------------------|
| AI 识别准确率不足 | 持续优化 prompt，考虑使用更强大的视觉模型；允许用户手动修正识别结果 |
| 用户留存率低 | 通过体检报告 → 建议的闭环增加粘性；加入饮食打卡和成就系统 |
| 竞品快速跟进（薄荷等） | 聚焦"体检+饮食"差异化定位，建立医学专业壁垒 |
| 健康建议的法律合规风险 | 标注"仅供参考，不构成医疗建议"；后续聘请医学顾问审核规则 |
| 盈利模式不清晰 | 先用免费版验证 PMF，达到 1 万 DAU 再开启订阅 |
| 数据隐私与安全 | 采用行业标准加密，用户数据不外泄；合规存储 |

**下一步最重要的事：**
1. 找 10-20 个真实用户进行为期 2 周的测试
2. 收集 AI 识别准确率和用户满意度数据
3. 验证"体检报告 → 饮食建议"的需求强度
4. 根据反馈迭代产品

## 十、我们想说的话

我们相信，每个人都应该能够轻松地了解自己吃进去的每一口食物。现代人面临越来越多的慢性病风险，但饮食管理仍然停留在"凭感觉"或"翻表格"的阶段。通过 AI 技术，我们把专业的营养分析能力放进了每个人的口袋。

我们不只是帮助用户记录热量，更是帮助他们理解——根据自己的身体情况，应该怎么吃。中西医结合的视角，让我们的产品既有科学严谨性，又有文化温度。

这是一款还在成长中的产品，但我们相信它的方向是对的。因为每一次技术的进步，都应该让普通人的生活变得更好一些。
